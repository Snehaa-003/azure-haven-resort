# 🌊 Azure Haven — Luxury Resort Website

> **Where the Ocean Meets Tranquility**

Azure Haven is a modern, responsive luxury resort website concept designed for a boutique coastal retreat in Goa, India.

The project focuses on creating a premium hospitality experience through elegant UI design, immersive imagery, responsive layouts, and interactive booking and gallery sections.

🔗 **Live Demo:** https://azure-haven-resort-nu.vercel.app/

---

## ✨ Features

- 🏝️ Premium resort landing page
- 🛏️ Rooms & Suites showcase
- 📅 Interactive booking / stay interface
- 🖼️ Full resort gallery
- 🌴 Resort experiences and amenities section
- 💬 Guest testimonials section
- 📍 Contact and location information
- 📱 Fully responsive design
- ✨ Smooth UI interactions and animations
- 🎨 Modern luxury-focused visual design
- ♿ Accessible and user-friendly interface

## 📄 Website Sections

### 🏠 Home
A visually immersive hero section introducing Azure Haven, followed by the resort story, featured rooms, experiences, guest reviews, gallery preview, and booking call-to-action.

### 🛏️ Rooms & Suites
Showcases the available room categories with images, descriptions, sizes, and pricing.

### 🌿 About
Introduces the resort concept, its atmosphere, and the overall guest experience.

### 🖼️ Gallery
A visual gallery designed to showcase the resort, rooms, surroundings, and coastal experience.

### 📅 Booking
Provides a booking-oriented interface where visitors can select their check-in date, check-out date, and number of guests.

### 📩 Contact
Provides resort contact and location information for visitors.

## 🚀 Running the Project Locally

### 1. Clone the repository

```bash
git clone https://github.com/Snehaa-003/azure-haven-resort.git
```

### 2. Navigate into the project

```bash
cd azure-haven-resort
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at the local development URL shown in your terminal.
